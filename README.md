Wkly is a minimalist, structured weekly planner built to eliminate the visual noise and free-form clutter of traditional workspace apps. Instead of an infinite blank canvas, Wkly uses a fixed 7-day grid and dynamic, conditional form entries to log exactly what matters.

Core Features:

Ultra-Minimalist UI: A fiercely simple, uncluttered interface that relies on generous negative space and a unified background to keep you focused.

Structured Data Entry: Specific, dynamic forms for Studying (tracking subjects and durations) and Training (tracking exercises, sets, and reps) rather than messy text blocks.

Pastel Pop Color-Coding: Vibrant, user-selected pastel tags (Pink, Blue, Green, Yellow, Lavender) to visually organize the week at a glance.

AI-Powered Parsing: Built-in integration with Google AI Studio to convert natural language requests directly into strictly formatted JSON tasks.

Full-Stack MERN Architecture: Built securely with MongoDB, Express, React, and Node.js.
